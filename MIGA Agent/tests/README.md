# Проверки Agent

Строгий импорт приглашений v2 без WPF, службы и сетевого подключения:

    dotnet run --project "MIGA Agent/tests/InvitationTests.csproj" --configuration Release

Проверяются допустимое DNS-имя, дублирующиеся поля JSON, неизвестная версия, диапазон портов, размер ID, IPv6, неизвестные поля, неканонический Base64URL и предельная длина.

Release-сборка Agent не доказывает работу административного named pipe, DPAPI, SSH-команд или настоящего туннеля. Эти действия требуют отдельных интеграционных проверок.

QR smoke: синтетическое приглашение miga2 кодируется QRCoder в PNG; проверяется сигнатура PNG. Это не проверяет считывание камерой Android.

Разделение Client/Admin: тесты проверяют однократную миграцию независимого списка VPS без паролей и клиентских правил, сохранение повреждённого файла, QR encode/decode, границы идентификатора/данных IPC, отказ подмены пути процесса и реальный handoff между изолированными тестовыми процессами. Последний тест требует обычного пользовательского токена вне restricted sandbox; установленные приложения, службы и конфиги не используются.

Закрытие с несохранённым черновиком, восстановление правил после сохранения и отзывчивость WPF при задержке запуска и тайм-ауте остановки подменённой службы:

    dotnet run --project "MIGA Agent/tests/ClientUi/ClientUiTests.csproj" --configuration Release

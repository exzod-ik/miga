# Удаление protocol v1

Поддерживается только v2 в Windows-клиенте, Linux-сервере, MIGA Agent и Android. Agent переносит правила из старого Windows-конфига, Android переносит правила схем 1–4. Старые ключи и приглашения не преобразуются; для подключения нужно новое приглашение miga2. Это миграция настроек, а не поддержка старого транспорта.

Удалены XOR/swap, случайный рабочий порт на пакет, raw UDP-сервер, ServerCore и его таблицы/пулы портов, старые команды генерации ключей и обновления конфига, ветка установщика v1, старые форматы обмена настройками, тесты удалённого wire format и UdpPacketAssembler.

Сохранены общие механизмы TUN, NAT/conntrack, PID/DNS/FlowTable, контрольные суммы и сетевые показатели. Версия MigaDiagnostics-v1 относится к независимому IPC API диагностики, а не к транспортному протоколу.

Точка отката: Artifacts/previous-builds/backups/before-v1-removal-20261114-193911. Исходные пользовательские изменения сохранены в архиве; установленное ПО и VPS не изменялись.

## Проверки

- Windows: Release-клиент, Agent и MSI собраны; полный набор клиентских регрессий прошёл. Отдельный loopback-тест реальной v2-сессии проверяет Noise/BIND/ADD_ADDRESS/RESUME/CLOSE, потерю READY/STATUS, повреждённый ответ и Stop.
- Linux: сборка на отдельном сборочном хосте; независимые проверки wire format, SQLite и изолированного сервера с подменённым TUN прошли. Фактический SO_RCVBUF сессии — 8388608 байт. Общая клиентская сессия проверяется также с IPv4-mapped IPv6 сокетами, используемыми Android.
- Android: JNI собран для arm64-v8a, armeabi-v7a, x86, x86_64. APK содержит соответствующие библиотеки. 35 тестов приложения и lint прошли; в полном ядре 82 из 88 тестов прошли. Шесть сбоев относятся к неизменённым LocalDirectSocks-тестам локальных соединений и таймингов; отдельный прогон исходной копии также даёт сбои этого набора. Полный Android-набор не считается прошедшим.
- Установщики проверены сборкой MSI и bash -n; установка, реальный WinDivert-трафик, Android-устройство и работа с действующим VPS не проверялись и не запускались.

Политика конфиденциальности M.I.G.A.

Дата обновления: 2 октября 2026 года.

Приложение: M.I.G.A. для Android, идентификатор пакета org.miga.android.

Разработчик: exzod-ik.
Контакт по вопросам конфиденциальности: exzod.usa@gmail.com.

Назначение приложения

M.I.G.A. — клиент для выборочной маршрутизации сетевого трафика через серверы M.I.G.A., которые пользователь добавляет самостоятельно. Для использования приложения не требуется создавать учётную запись M.I.G.A. Приложение не предоставляет встроенный каталог VPN-серверов.

Эта политика описывает Android-клиент. Если вы используете сервер другого лица, обработка данных на этом сервере зависит также от его оператора. Прежде чем подключаться, ознакомьтесь с условиями и политикой оператора сервера.

Данные на устройстве

Для работы приложение обрабатывает названия и адреса добавленных серверов, диапазоны портов, ключи профилей, назначения приложений, правила IP-адресов и доменов, выбранную тему интерфейса и состояние подключения.

Приложение получает от Android список доступных для запуска приложений, включая их названия и идентификаторы пакетов, чтобы пользователь мог выбирать правила маршрутизации. Настройки и назначения сохраняются в приватном хранилище приложения. Ключи профилей сохраняются в зашифрованных файлах с использованием AES-GCM и Android Keystore. Резервное копирование данных приложения средствами Android отключено в его конфигурации.

В текущей версии нет встроенных рекламных или аналитических SDK и отдельной функции отправки телеметрии разработчику. Список приложений и настройки не отправляются разработчику отдельным каналом аналитики.

Сетевой трафик и DNS

После разрешения пользователя приложение использует Android VpnService для обработки сетевых пакетов и применения правил маршрутизации. Оно обрабатывает IP-адреса, порты, сведения о соединениях, содержимое передаваемых пакетов и DNS-запросы и ответы, необходимые для работы правил по доменам.

Трафик, выбранный для туннелирования, передаётся настроенному серверу M.I.G.A. DNS-запросы могут направляться через основной сервер и дополнительные серверы в соответствии с настройками и логикой маршрутизации. Трафик, не выбранный для туннелирования, может передаваться напрямую. IPv6 передаётся напрямую.

Оператор сервера получает данные, необходимые для обработки соединения, включая внешний IP-адрес клиента, адреса и порты назначения и переданные пакеты. Незашифрованное на уровне исходного приложения содержимое может быть доступно оператору сервера. Обработку DNS-запросов также выполняют соответствующие DNS-серверы. Сроки хранения журналов и иной информации на удалённых серверах определяются их операторами; Android-клиент не управляет этим хранением.

Статистика соединения и счётчики трафика используются для отображения состояния работы приложения. Приложение не предоставляет пользователю архив посещённых сайтов или содержимого сетевого трафика.

SSH и импорт QR-кодов

При добавлении сервера через SSH приложение использует введённые пользователем адрес, логин и пароль для подключения к выбранному серверу и чтения его конфигурации. SSH-пароль не сохраняется в постоянных настройках приложения. Полученные параметры и ключи профиля сохраняются на устройстве для последующих подключений.

Разрешение камеры используется для сканирования QR-кода настроек сервера. Из QR-кода извлекаются параметры подключения и ключи профиля. Функция сканирования не предназначена для сохранения фотографий или их отправки разработчику. QR-коды настроек содержат секретные значения: не публикуйте их и не передавайте посторонним.

Безопасность и разрешения

Доступ к сети необходим для VPN-соединений и импорта через SSH. Доступ к состоянию сети используется для управления соединением. Активная служба поддерживает VPN во время работы и отображает постоянное уведомление. Пользователь может остановить соединение в приложении.

Шифрование локального хранилища ключей не означает криптографическую защиту туннеля. Текущий протокол M.I.G.A. использует преобразование XOR и перестановку байтов и не обеспечивает аутентификацию пакетов, криптографическую целостность или защиту от повторной передачи. Не полагайтесь на M.I.G.A. как на средство обеспечения анонимности или защиты конфиденциальных данных. Используйте защищённые протоколы исходных приложений, например HTTPS, и доверенные серверы.

Хранение и удаление

Сохранённые настройки и ключи профилей остаются на устройстве до их изменения, удаления или удаления данных приложения. Для удаления профиля остановите VPN, снимите связанные назначения и правила и удалите профиль в разделе серверов.

Чтобы удалить все локальные данные приложения, воспользуйтесь функцией очистки хранилища в настройках Android или удалите приложение. Очистка данных на устройстве не удаляет журналы и другие данные на удалённых серверах. По вопросам удаления таких данных обращайтесь к оператору соответствующего сервера.

Изменения и обращения

При изменении функций приложения эта политика может обновляться. Дата актуальной редакции указана в начале документа. По вопросам обработки данных обращайтесь по указанному выше контактному адресу.
